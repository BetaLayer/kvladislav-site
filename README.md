# kvladislav — личный сайт RU / EN

Сайт: https://betalayer.github.io/kvladislav-site/

Личный сайт-портфолио: репетиторство по математической статистике, подготовка к ACT-практике и Zei — ИИ-ассистент медицинского психолога.

## Как обновлять

1. Измените файлы через GitHub или локальный редактор.
2. Сохраните изменения в ветку `main`.
3. GitHub Pages автоматически опубликует новую версию. Статус доступен во вкладке **Actions**.

Сборка и установка зависимостей не нужны. GitHub Pages публикует корень ветки `main`; `.nojekyll` отключает обработку Jekyll.

## Файлы

- `content.js` — имя, email и все тексты в словарях `ru` и `en`.
- `index.html` — главная страница. При изменении текста обновляйте также русский запасной текст в HTML, который виден без JavaScript.
- `act.html` — отдельная страница будущей ACT-практики.
- `app.js` — переключение языка, выбор темы письма и копирование email.
- `styles.css` — оформление и адаптивная вёрстка.
- `favicon.svg` — значок сайта.

Русский язык открывается по умолчанию. Выбор сохраняется в браузере. Прямая ссылка на английскую версию: https://betalayer.github.io/kvladislav-site/?lang=en

Для локального просмотра откройте `index.html` в браузере. Копирование email работает на HTTPS или localhost. Кнопки связи открывают почтовую программу и не отправляют письмо автоматически.

Шрифты загружаются из Google Fonts; при отсутствии сети используются системные. Других внешних ресурсов, аналитики, базы данных и форм сбора данных нет.
